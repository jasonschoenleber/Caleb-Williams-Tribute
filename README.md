# Caleb Williams Tribute

An unofficial, interactive fan page celebrating Caleb Williams' records, Next Gen Stats moments and clutch plays with the Chicago Bears. Not affiliated with the Chicago Bears or the NFL.

## View the site
Once GitHub Pages is on, the page lives at:
https://jasonschoenleber.github.io/Caleb-Williams-Tribute/

## Files
- `index.html` — the page (styles and scripts included)
- `assets/iceman.jpg` — hero image
- `assets/dj_catch.mp4`, `assets/CL_TD.mp4` — looping clips in the comeback section

## Update the YouTube playlist
Open `index.html`, find `const PLAYLIST_ID =` and paste the full value after `list=` from your playlist link.
